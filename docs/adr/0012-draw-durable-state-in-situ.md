# Draw durable state in situ

PKSX draws durable app and workspace state on the object that state belongs to, and keeps toasts for transient outcomes of user actions. This supersedes ADR 0009, which committed PKSX to a persistent status strip for the same state. The app shell reserves no height and no width at rest, so a persistent strip has nowhere to live, and the state it narrated is better expressed where the user is already looking: a carried Pokemon Entity binds to Controller Focus and travels with it instead of being named in text, busy is shown by the region doing the work, and a Box Source carries its own identity. ADR 0009's toast half survives unchanged, and import errors move onto it because they are outcomes of a user action rather than durable state.

ADR 0009's goal was scannable controller-first context, and a single status line cannot deliver it. The strip carries one message at a time behind a priority order, so a user carrying a Pokemon Entity while the Workspace is dirty sees only one of the two. It also has to be read, which is the wrong demand at the 616 by 336 landscape floor set by the viewport budget, where the strip and the persistent bars that justified it cost about 35 percent of the available height. Two of the app's five Focus Zones existed only to service that chrome, and they carried more of the controller navigation model than all three content zones combined.

Dirty Workspace gets no ambient indicator at all, which is the part most likely to look like an oversight later. It is persisted and restored across reload, so unexported changes are not a loss risk, and the one action that destroys a Dirty Workspace is Backup Restore, which already warns at the point of loss. A warning at the moment of loss is the correct shape for that risk and costs no layout. Empty-library guidance becomes screen content rather than status, so the empty box-first surface leads with import instead of showing an empty Box Source.
