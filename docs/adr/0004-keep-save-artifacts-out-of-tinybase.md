# Keep save artifacts out of TinyBase

PKSX stores raw imported save bytes and backup bytes behind a platform-specific Saves storage adapter, while TinyBase is reserved for the reactive editor workspace, parsed projections, dirty state, validation output, UI state, and Cloud Sync bookkeeping. TinyBase may replicate immutable, uniquely identified revision records, but its merge result never selects Shared Sync State or discards competing revisions. The provider-neutral sync coordinator enforces causal authority, conflict preservation, and recovery. The web/PWA adapter can start with IndexedDB, but native Capacitor builds should add a native-capable adapter instead of relying on WebView IndexedDB for durable save artifacts; this keeps unchanged exports byte-for-byte faithful and lets storage durability vary by platform without leaking into UI or PKHeX Engine code.
