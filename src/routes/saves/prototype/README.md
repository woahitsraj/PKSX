# Saves layout prototype

This is a reference artifact from [issue #180](https://github.com/woahitsraj/PKSX/issues/180), not the production Saves implementation.

- Variant A, Cartridge grid, is the selected direction.
- Variants B and C are discarded alternatives retained for comparison.
- The issue resolution and `CONTEXT.md` are authoritative when the prototype differs from the final behavior.

Run `pnpm prototype:saves`, then open `/saves/prototype?variant=A`. The route renders the prototype only in development.
